# Dotfiles - Arch Linux 

1. clone repository into `~/.dotfiles`
2. change permission with `chmod +x ~/.dotfiles/link_dotfiles.sh`
3. execute script `~/.dotfiles/link_dotfiles.sh`

## Sync Git
- git init
- git add .
- git commit -m "initial commit"
- git remote add origin `git@github.com:Yanneckb00/archlinux-dotfiles.git`
